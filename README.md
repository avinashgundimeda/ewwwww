# Nexora Technologies Website

A responsive, multi-page website for Nexora Technologies, a software development, IT services, cybersecurity, digital marketing, and internship training company.

## Pages

- `index.html` - Home page
- `about.html` - Company overview
- `services.html` - Services offered
- `internships.html` - Internship programmes
- `contact.html` - Contact form and company details

## Features

- Responsive layout for desktop, tablet, and mobile screens
- Light and dark theme toggle with saved preference
- Mobile navigation menu
- Service detail panels
- Internship programme cards
- Testimonials carousel
- Login and sign-up dialog UI
- Client-side form validation
- Accessible labels, focus states, and skip navigation

## Run Locally

No build step or package installation is required.

### Option 1: Open directly

Open `index.html` in a browser.

### Option 2: Start a local server

From the project directory, run:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
